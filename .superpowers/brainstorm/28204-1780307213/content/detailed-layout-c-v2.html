修正总结

✅ 所有指标都有数据源支撑

  • 成员数 → members 表 COUNT
  • 待处理邀请 → invitations WHERE status='pending'
  • 活跃 API Key → api_keys WHERE revoked_at IS NULL
  • 审计事件 → audit_logs COUNT + GROUP BY date
  • 系统状态 → /healthz + /readyz 端点
  • 角色分布 → members + rbac roles 表
  • 成员增长 → members.created_at 按天聚合
  • 审计趋势 → audit_logs.created_at 按天聚合

❗ 不纳入的内容及原因

  • API Key 调用量 — 无计数器，属于计费/配额域，模板不覆盖
  • 错误率/响应延迟 — 无 APM 集成，属于可观测性域
  • 实时活跃用户 — 无 WebSocket/在线状态追踪
